# Choose where to reduce work per approved Profile

Type: grilling
Status: resolved
Blocked by: 01

## Question

Given the measured costs, which workflow change, if any, merits a trial, and what result would justify adopting it while retaining current depth, English evidence checks and Russian fidelity checks?

## Answer

Trial one change on the next unwritten Profile. In the evidence-first workflow, have the writer choose each displayed Key Moment and Deep Fact citation from trustworthy sources it fetched and used to support that passage. Wikipedia is optional. Keep current Profile depth, independent English evidence review, and independent Russian fidelity review, including the existing corroboration rules.

Keep the change if the first English audit finds zero citation mismatches and no new citation-quality issues. Review the result after each Profile as part of ongoing pipeline improvement. Use the existing pilots as context and continue with successive Profiles without scheduling matched controls.

Record first-audit citation blockers, English repair rounds, elapsed time, and both usage meters. Judge overall work by weekly plan usage per bilingual approval across successive attempts, including usage from held attempts. The first audit establishes whether the citation handoff worked. The accumulated runs show whether overall work fell.
