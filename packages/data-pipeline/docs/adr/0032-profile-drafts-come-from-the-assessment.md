# Profile drafts come from the assessment

A writer supplies the final wording and evidence in one assessment. Each reader-facing field carries its exact text and findings. The same extraction step produces the draft and the field-indexed findings for writing and repair. Finalization adjusts Connection findings when a target falls outside the dataset.

The CLI saves the extracted draft and a pending assessment bound to its content hash in one record. Once a fresh independent audit runs, the report retains the assessment. An evidence-only retry uses the same extraction step and preserves the draft and its repair count. Existing drafts and receipts remain eligible under the established checks. New drafts store claims in the assessment and verification report only.
