# Profile drafting starts with fetched evidence

The coordinator assigns research and drafting to one agent. It fetches supporting sources before writing, stages the draft and saves the evidence assessment for independent audit. Each Key Moment and Deep Fact cites a fetched source that supports its central claim.

Remove the standalone `profiles write` command because its provider calls did not supply fetched evidence. Provider API commands continue to verify, audit and translate finalized Profiles. Finalization still accepts staged files with writer provenance.
