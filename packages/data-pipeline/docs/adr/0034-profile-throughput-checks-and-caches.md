# Profile drafting starts with prefetched sources and local preflight

The coordinator prepares Source Maps before dispatching writers. Prefetch ranks Wikipedia references, records recent deterministic access failures, and writes to the URL and content-hash cache used by evidence reads. A Source Map lists heading offsets for targeted reads. Each cited claim still needs its own checked evidence.

Preflight checks staged and finalized drafts using local snapshots and the same mechanical and assessment rules as verification. Writers and repair agents run it before handing back a draft. Finalization and independent verification retain their identity, adversarial evidence, audit and receipt checks.

Profile commands share a subject index keyed by raw input file stats. Output refreshes the index from its existing rows, and publishing omits it. The same index supplies Russian terminology to translation and fidelity audit. English passages remain the source for facts. The prompt changes preserve existing receipt policies.
