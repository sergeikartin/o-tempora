# Profile verification seeks independent counterevidence

The writer's evidence can repeat the same historical myth across multiple sources, and a flat excerpt can hide that an article presents a quote as disputed. Preserve normalized document titles and heading offsets in new source snapshots. Associate quotes with their heading breadcrumbs in the audit and confine nearby context to the same section. Continue accepting cached snapshots under their original hashes.

Before the independent English audit, select up to five supported claims. Prioritize Deep Facts, claims requiring corroboration, and passages with cues such as long quotations, superlatives or legends. Search for the relevant subject and aspect using neutral and falsification queries. Only locally fetched, mechanically verified excerpts can enter the assessment. Keep the finding's verdict and supporting evidence intact. The independent auditor decides whether the wording accommodates the competing accounts.

Provider verification shares the source cache and a budget of six Responses turns, six web search calls and eight source reads across the Profile's repair rounds. Within a run, unchanged passage paths and claims reuse their checks. The coordinator uses a separate hash-bound task and stores the result alongside the draft until audit. This adds a bounded research step for high-risk claims and leaves lower-risk Profiles on the existing audit path. A transient fetch failure or exhausted provider budget leaves the verification retryable.

Policy 7 reports record the model, queries, outcomes and counterevidence, and require complete checks for selected findings unless the API run explicitly opts out. Existing approvals under policies 3 through 6 remain eligible. Policy 2 approvals remain eligible for closed spans and point dates. Output continues to use the receipt and its report.
