# Data licensing

This package's generated data (`src/data/*.json`) is derived from third-party
datasets. Each source's license and attribution requirements apply to the
fields it contributes — see below. This notice covers only the *data*;
the source code of this repository is licensed separately (or not yet
licensed at all, as of this notice).

## People (`people.json`) — Pantheon 2.0

Sourced from [Pantheon 2.0](https://pantheon.world/data/datasets) by
[Datawheel](https://datawheel.us/), licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
(Attribution-ShareAlike). Descriptions are additionally sourced from
Wikidata (CC0), keyed on the Wikidata QID Pantheon retains per person.

Required citation:

> Yu, A. Z., et al. (2016). Pantheon 1.0, a manually verified dataset of
> globally famous biographies. *Scientific Data* 2:150075.
> doi: [10.1038/sdata.2015.75](https://doi.org/10.1038/sdata.2015.75)

Per CC BY-SA 4.0 Section 3(b), this derived/transformed subset of Pantheon's
fields is itself licensed under CC BY-SA 4.0.
